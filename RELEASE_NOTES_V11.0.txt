MY FINANCE TRACKER 11.0 — PREMIUM UI/UX UPDATE 2 (BUILD 32)

Architecture
- Real package declarations now match presentation, navigation, feature and infrastructure boundaries.
- MainActivity remains a small application/session host.
- Data, security and notification sources contain no Compose or feature dependencies.
- ReminderReceiver moved to its infrastructure package and the manifest was updated.
- Architecture tests enforce package declarations and dependency restrictions.
- Feature-parity tests retain all critical workflows and compatibility keys.
- Dashboard, payments, expenses, reports and settings expose immutable feature-specific UI state projections.

Design system and experience
- Calm Financial semantic light/dark palettes, typography, spacing, shapes and content-width rules remain authoritative.
- Shared form headers, fields, date controls, dropdowns, confirmations, attachment controls and settings rows remain centralized.
- Form/detail headers now use a consistent elevated premium surface and clearly label view-only records.
- English, Bangla, dark mode, country flags, offline country search and currency defaults remain available.
- No form field, action, filter, status, document workflow or safety confirmation was removed.
- Phones retain labeled bottom navigation; displays 840dp and wider use a labeled navigation rail.
- Dashboard commitment cards stack on narrow screens and with constrained text space.
- Payment-plan cards share consistent premium surfaces, shapes and elevation.
- Shared headings expose accessibility semantics and empty payment lists use bilingual guidance.
- Feature and shared-UI layout spacing now uses the centralized FinanceSpacing scale instead of screen-specific numeric values.
- Reports, expenses, payment lists and document pages share premium empty-state treatment.
- Report PDF/XLSX saves now provide accessible success or error feedback.
- Report, expense and payment cards use consistent semantic surfaces, shapes and elevation.
- Forms are centered and constrained to the professional form width on landscape, tablet and foldable displays.
- Dashboard cards stack when the available width is narrow or Android font scaling is 130% and above.
- Navigation labels use scalable theme typography and safe ellipsis while preserving full accessibility labels.
- Payment-request actions adapt to two rows for narrow or large-text layouts.
- Interactive plan cards expose button semantics and compact controls enforce a 48dp minimum touch target.
- Report filters, expense summaries and payment progress use restrained state-change animations only.

Reports
- Structured report blocks remain the common PDF document input.
- Branded PDF headers, semantic sections, field rows, signatures, pagination and ownership footers remain supported.
- PDF wrapping uses measured rendered width for clearer Bangla text, long names and payment instructions.
- Professional XLSX retains eight organized sheets, numeric money cells, metadata, frozen/filterable headers and print settings.

Compatibility
- Package/application ID and release signing configuration are unchanged.
- Version 10 encrypted data, attachments, JSON keys, encrypted backups and supported legacy restore remain compatible.

Release gate
- Build 32 is Premium UI/UX Update 2 of 3. It becomes installable after GitHub unit tests and APK/AAB generation pass.

# Version 9 feature-parity checklist

All Version 8.3 features are preserved: authentication, bilingual UI, theme, ownership/profile/signature, country/currency, Bangladesh and custom institutions, encrypted records/backups/attachments, reminders, EMI/loan/debt/expense workflows, payment controls and receipts, requests, confirmations, search/sort/filter, PDF and XLSX reports.

No JSON key, encryption format, application ID or supported backup format is removed or rewritten. Completed and archived records remain read-only until reopened or restored. Existing money values are never silently converted.

Version 9 adds the searchable offline ISO country catalog with generated flags and automatic currency defaults; typed navigation and centralized validation foundations; structured report models; and eight organized Excel sheets including split debt directions and payment requests.

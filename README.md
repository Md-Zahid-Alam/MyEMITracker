# My EMI Tracker — Version 1

A simple offline Android app for tracking one personal phone EMI plan.

## Features

- Add/edit phone EMI details
- Calculates monthly EMI
- Dashboard with paid/remaining installments
- Mark installments as paid
- Payment history
- Local storage using SharedPreferences
- Bangladesh Taka (৳) display
- Material 3 Jetpack Compose UI

## Requirements for building

- Android Studio
- Android SDK 35
- JDK 17
- Gradle wrapper can be generated by Android Studio

## Important

Version 1 includes the notification channel foundation, but automatic scheduled EMI reminders are not yet implemented. They can be added in Version 2 using AlarmManager/WorkManager.

## Build

Open this project in Android Studio, allow Gradle sync, then use:

Build > Build App Bundle(s) / APK(s) > Build APK(s)

The debug APK will normally be under:

app/build/outputs/apk/debug/app-debug.apk
